Step 2: Getting the Code Locally 
Every group member needs a copy of the repository on their own computer. 
[1] On Github repository page, click the green "<> Code" button on your right and copy the HTTPS clone URL.
[2] Open your computer terminal (or Git Bash kung meron) and run:  
          git clone <PASTE_URL_HERE>
[3] Move into the newly created project folder
          cd your-repository-name

NOTE: download the database cafedb.sql
